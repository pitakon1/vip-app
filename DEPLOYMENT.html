二、云服务商选择与地域决策

2.1 地域延迟对比

地域 泰国延迟 国内延迟 ICP 备案 PDPA 适用场景
新加坡（推荐主节点） 40–60ms 80–120ms 不需要 数据出境需告知 App + Web 主体
泰国曼谷（AWS ap-southeast-7） 10–30ms 180–250ms 不需要 最合规 仅泰国用户
香港 80–120ms 40–80ms 不需要 中性 国内偏多
国内（深圳/上海） 180–250ms 10–30ms 必须 数据出境审批 小程序必备

2.2 推荐云厂商

厂商 推荐度 理由
阿里云（新加坡 + 国内） ★★★★★ 新加坡节点稳定、国内备案顺畅、中文控制台、生态全、价格适中
腾讯云（新加坡 + 国内） ★★★★☆ 价格略低、小程序生态好、海外节点稳定性略逊阿里
AWS（新加坡/曼谷） ★★★☆☆ 曼谷节点对泰国最优，但价格贵 30–50%，国内访问差，控制台复杂
华为云 ★★★☆☆ 国内好，海外节点少

2.3 推荐架构（双区域）

┌─────────────────────────────────────────────────────────┐
│  海外主节点（阿里云新加坡）                                 │
│  ┌──────────┐  ┌──────────┐  ┌──────────┐               │
│  │ FastAPI  │  │PostgreSQL│  │  Redis   │  ← App/Web/业主端 │
│  │  后端    │──│  主库    │  │  缓存    │               │
│  └──────────┘  └──────────┘  └──────────┘               │
│  ┌──────────┐  ┌──────────┐                            │
│  │ Nginx +  │  │   OSS    │  ← 房源图片/合同文件         │
│  │ 前端静态 │  │ 对象存储 │                            │
│  └──────────┘  └──────────┘                            │
└─────────────────────────────────────────────────────────┘
              ↑ HTTPS 回源（仅 API 请求）
┌─────────────────────────────────────────────────────────┐
│  国内节点（阿里云深圳/上海）                                │
│  ┌──────────┐  ┌──────────┐                            │
│  │ 小程序    │  │  ICP 备案 │  ← 微信小程序用户           │
│  │ API 网关 │──│  域名     │                            │
│  └──────────┘  └──────────┘                            │
└─────────────────────────────────────────────────────────┘
              ↑ CDN 加速
┌─────────────────────────────────────────────────────────┐
│  CDN：Cloudflare（海外免费版）+ 阿里云 CDN（国内按量）       │
└─────────────────────────────────────────────────────────┘

决策理由： - 新加坡到泰国延迟低、到国内可接受、无需备案、国际带宽充足 - 国内节点仅服务小程序，体量小、成本低，解决 ICP 合规 - 数据主库放新加坡（数据源在泰国），国内不存敏感数据，只转发请求

七、推荐落地路径

当前阶段（0–2k DAU）— 月费 ¥300–600

立即购买：

项 规格 厂商 月费
新加坡轻量服务器 2核4G / 100G SSD / 5Mbps 阿里云 ¥150–250
国内轻量服务器 2核2G / 50G SSD / 3Mbps 阿里云 ¥60–100
域名 .com ×1 阿里云 ¥5/月
短信包 国内 + 泰国 阿里云/AIS ¥50–200

部署清单： 1. 新加坡服务器：Docker Compose 部署 FastAPI + PostgreSQL + Redis + Nginx 2. 国内服务器：Nginx 反向代理 + 备案域名，HTTPS 回源新加坡 3. 域名解析：api.xxx.com → 新加坡，mp.xxx.com → 国内（备案） 4. SSL：Let's Encrypt 自动续签 5. CDN：Cloudflare 免费版套在海外域名前 6. 备份：crontab 每日 pg_dump 到 OSS

何时升级到阶段 2： - DAU 超过 2,000 - CPU 平均负载 > 70% - 数据库连接数频繁告警 - 房源图片存储 > 50G

八、价格说明

  • 以上价格为 2026 年公开挂牌价区间参考，实际以云厂商官网为准
  • 包年付通常有 6–8 折优惠，包三年 5–6 折
  • 新用户首单常有 1–3 折活动，建议用新账号购买首单
  • 泰国本地服务（AIS/TrueMove）需用泰铢结算，汇率按 ฿1 ≈ ¥0.2 估算
  • 支付通道费率可随交易量增长与渠道商议价降低
